- Stabilize project boundaries after repository consolidation
- Keep documentation aligned with actual apply order and ownership

## Mid term

- Add architecture diagrams and flow visuals
- Add safer examples for common Terraform operations

## Longer term

- Add repeatable validation pipelines for docs and Terraform structure
- Publish opinionated patterns for small-team platform operations
- Add curated sample scenarios for learning paths

## Out of scope (public repo)

- Private application operations and secrets from companion repositories
- Environment-specific production values and credentials
