# Code of Conduct

## Our commitment

We want this project to be a respectful, inclusive, and useful place to learn and collaborate.

## Expected behavior

- Be respectful and constructive
- Assume good intent and ask clarifying questions
- Focus feedback on ideas and implementation, not people
- Share context and evidence when proposing changes

## Unacceptable behavior

- Harassment, intimidation, or personal attacks
- Discriminatory language or behavior
- Publishing private or sensitive information without consent
- Repeated bad-faith disruption of project discussions

## Enforcement

Project maintainers may remove, edit, or reject contributions and comments that violate this code of conduct.

## Reporting

For conduct concerns, contact the maintainer privately.
